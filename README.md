 Salah satu pendekatan yang sering digunakan adalah Finite State Machine (FSM), yaitu metode yang membagi perilaku menjadi beberapa state (keadaan) seperti idle, patrol, chase, dan attack. Namun, ketika implementasi FSM dilakukan secara konvensional dalam satu script, kode cenderung menjadi kompleks, sulit dibaca, dan kurang mudah untuk dikembangkan. Dengan memanfaatkan Scriptable Object, setiap state dalam FSM dapat dipisahkan menjadi modul tersendiri yang reusable dan independen.
